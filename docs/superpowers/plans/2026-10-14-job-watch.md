# Job Watch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Watch each lead's public applicant-tracking board (Greenhouse, Lever, Ashby) for web, design, SEO, CRO and marketing roles, surface new and long-open roles on Today, and let the email drafter mention a role that is verifiably open.

**Architecture:** Two new tables (`career_sources`, `job_postings`) hold one board per lead and the roles seen on it. A scheduled job (its own cron) first polls active boards, then discovers boards for leads that have been scanned but not yet checked. Discovery reuses the careers link the crawler already stores on the audit (`audit.site_links.careers`). A new `open_role` Today item and a posting-aware draft prompt sit on top of that data. The careers watcher is deliberately an input to the existing scanner, not a separate product.

**Tech Stack:** TypeScript, Hono, Cloudflare Workers + D1 + cron triggers, Vitest (`@cloudflare/vitest-pool-workers`), React + Vite, Zod.

**Spec:** [`reports/Hidden job market web dev CRO SEO.md`](../../../reports/Hidden%20job%20market%20web%20dev%20CRO%20SEO.md) (research report, sections "A careers watcher is cheap to build, and the seed list is the moat" and "What to do this week"). Raw notes are in `research_notes/Hidden job market web dev CRO SEO/`.

## Global Constraints

- Read only keyless, public job-board endpoints, exactly these: Greenhouse `GET https://boards-api.greenhouse.io/v1/boards/{token}/jobs`, Lever `GET https://api.lever.co/v0/postings/{site}?mode=json`, Ashby `GET https://api.ashbyhq.com/posting-api/job-board/{name}`. Never scrape LinkedIn, Indeed or Glassdoor.
- At most `JOB_WATCH_MAX_PER_TICK = 40` boards or discoveries per scheduled run (Workers subrequest budget; the app already needs the paid plan for Browser Rendering and Workflows).
- The approval step stays: the app writes drafts, it never sends mail.
- A role may be mentioned in a draft or shown as "Hiring" only if it was seen open on the board within the last 48 hours.
- No database foreign keys in this repo. `deleteBusiness` (`src/worker/db/businesses.ts`) deletes child rows table by table, so new tables with a `business_id` must be added to it.
- Migrations: the next number is `0022`. Apply locally with `npm run db:migrate:local`.
- Verification gate for every task: `npm run typecheck && npm test` green before commit. After the final task run `graft build`.
- Tests run inside the Workers pool: seed through `env.DB`, never touch the network (pass a fake `fetch`), and use a fixed `now` that changes between two calls whenever a test needs "later".
- Comments say why, in one line, like the surrounding code. Terse code, no new dependencies.
- Start from `main` in a fresh worktree. The current branch (`fix/full-time-voice-notes`) has unrelated uncommitted CRO edits that must not be mixed into this work.

## Review Focus

Failure modes the spec implies but no happy-path test would catch, most likely first. Each has a test in the task named in brackets.

1. **A board that answers "no jobs" or errors once closes every role and re-announces them as new on recovery.** Expected: closing needs two empty answers in a row, an error closes nothing, and a role that reappears is reopened, not "new". [Task 5]
2. **The first look at a board makes years-old roles look fresh.** Expected: roles found on the first successful sync are `baseline`, and with no date from the board their age is unknown, so Today never calls them fresh or stale. [Tasks 5, 7]
3. **Hostile or malformed board data.** A careers page can name any board token, a board can return a `javascript:` URL, and a role title is third-party text that goes into an AI prompt. Expected: tokens are validated before they are put in a URL, only `https://` role links are kept, and titles are flattened to one short line. [Tasks 3, 4, 9]
4. **Suppressed, archived, deleted and already-contacted leads.** Expected: they get no `open_role` item, a deleted lead leaves no orphan rows, and the `job_found` activity row does not count as contacting the prospect (otherwise it hides a stalled deal). [Tasks 1, 7]
5. **A draft claims a role that closed or was last seen days ago.** Expected: only a role open and seen within 48 hours is passed to the prompt, and the prompt tells the model to use the exact title and nothing else about the role. [Tasks 1, 9]

```sql
-- Where a lead hires: the public job board found on its careers page, and the roles seen on it.
-- status: active = a board we poll; none = no readable board (rechecked monthly); error = discovery failed (retried daily).
-- last_ok_at is the last time the board answered with valid JSON; NULL means the next sync is the first look (a baseline).
CREATE TABLE career_sources (
  business_id TEXT PRIMARY KEY,
  status TEXT NOT NULL,
  ats TEXT,
  token TEXT,
  careers_url TEXT,
  checked_at TEXT,
  last_ok_at TEXT,
  next_check_at TEXT NOT NULL,
  empty_streak INTEGER NOT NULL DEFAULT 0,
  last_error TEXT,
  created_at TEXT NOT NULL
);
CREATE INDEX idx_career_sources_due ON career_sources(status, next_check_at);

-- baseline = found on the first successful look at the board, so "first seen" says nothing about how old the role is.
CREATE TABLE job_postings (
  id TEXT PRIMARY KEY,
  business_id TEXT NOT NULL,
  external_id TEXT NOT NULL,
  title TEXT NOT NULL,
  url TEXT NOT NULL,
  location TEXT,
  department TEXT,
  role_kind TEXT,
  posted_at TEXT,
  first_seen_at TEXT NOT NULL,
  last_seen_at TEXT NOT NULL,
  closed_at TEXT,
  baseline INTEGER NOT NULL DEFAULT 0,
  UNIQUE (business_id, external_id)
);
CREATE INDEX idx_job_postings_business ON job_postings(business_id, closed_at);
-- Only open roles in our field are ever listed, so only they are indexed.
CREATE INDEX idx_job_postings_open_relevant ON job_postings(business_id) WHERE closed_at IS NULL AND role_kind IS NOT NULL;
```

```ts
import type { CareerSource, JobPosting, RoleKind } from "../types";
import { chunks } from "./chunks";

/** A board is only trusted for what it showed us recently: a role not seen for this long is not "open" for outreach purposes. */
export const SEEN_WITHIN_HOURS = 48;

type PostingRow = Omit<JobPosting, "baseline"> & { baseline: number };
const toPosting = (r: PostingRow): JobPosting => ({ ...r, baseline: r.baseline === 1 });

export type SourceWrite = Pick<CareerSource, "business_id" | "status" | "next_check_at"> & { checked_at: string }
  & Partial<Pick<CareerSource, "ats" | "token" | "careers_url" | "last_ok_at" | "empty_streak" | "last_error">>;

export const getCareerSource = (db: D1Database, businessId: string) =>
  db.prepare(`SELECT * FROM career_sources WHERE business_id = ?`).bind(businessId).first<CareerSource>();

/** Upsert. Callers pass the whole picture: a field left out is written as null (0 for the streak). */
export async function saveCareerSource(db: D1Database, s: SourceWrite) {
  await db.prepare(
    `INSERT INTO career_sources (business_id, status, ats, token, careers_url, checked_at, last_ok_at, next_check_at, empty_streak, last_error, created_at)
     VALUES (?,?,?,?,?,?,?,?,?,?,?)
     ON CONFLICT(business_id) DO UPDATE SET status = excluded.status, ats = excluded.ats, token = excluded.token, careers_url = excluded.careers_url,
       checked_at = excluded.checked_at, last_ok_at = excluded.last_ok_at, next_check_at = excluded.next_check_at,
       empty_streak = excluded.empty_streak, last_error = excluded.last_error`,
  ).bind(s.business_id, s.status, s.ats ?? null, s.token ?? null, s.careers_url ?? null, s.checked_at, s.last_ok_at ?? null,
    s.next_check_at, s.empty_streak ?? 0, s.last_error ?? null, s.checked_at).run();
}

export async function listDueSources(db: D1Database, nowIso: string, limit: number): Promise<CareerSource[]> {
  return (await db.prepare(`SELECT * FROM career_sources WHERE status = 'active' AND next_check_at <= ? ORDER BY next_check_at, business_id LIMIT ?`)
    .bind(nowIso, limit).all<CareerSource>()).results;
}

/** Scanned, non-archived leads with a website that have no board record yet, or whose "none"/"error" record is due for another look. */
export async function listUndiscovered(db: D1Database, nowIso: string, limit: number): Promise<{ id: string }[]> {
  return (await db.prepare(
    `SELECT b.id FROM businesses b
     WHERE b.archived_at IS NULL AND b.website_url IS NOT NULL
       AND EXISTS (SELECT 1 FROM audits a WHERE a.business_id = b.id)
       AND (NOT EXISTS (SELECT 1 FROM career_sources s WHERE s.business_id = b.id)
            OR EXISTS (SELECT 1 FROM career_sources s WHERE s.business_id = b.id AND s.status IN ('none','error') AND s.next_check_at <= ?))
     ORDER BY b.created_at, b.id LIMIT ?`,
  ).bind(nowIso, limit).all<{ id: string }>()).results;
}

export interface PostingWrite {
  external_id: string; title: string; url: string; location: string | null; department: string | null;
  role_kind: RoleKind | null; posted_at: string | null;
}

/**
 * Writes one sync of a board. New roles are inserted (`baseline` marks the first look at a board), known ones are refreshed and reopened,
 * and every open role not seen in this sync is closed. Callers must not call this with an empty list: whether an empty answer may close
 * roles is their decision (see closeAll).
 */
export async function applySync(db: D1Database, businessId: string, rows: PostingWrite[], nowIso: string, baseline: boolean): Promise<{ added: JobPosting[]; closed: number }> {
  const known = new Set((await db.prepare(`SELECT external_id FROM job_postings WHERE business_id = ?`).bind(businessId).all<{ external_id: string }>()).results.map((r) => r.external_id));
  const added: JobPosting[] = [], stmts: D1PreparedStatement[] = [], seen = new Set<string>();
  for (const r of rows) {
    if (seen.has(r.external_id)) continue;
    seen.add(r.external_id);
    if (known.has(r.external_id)) {
      stmts.push(db.prepare(

      ).bind(r.title, r.url, r.location, r.department, r.role_kind, r.posted_at, nowIso, businessId, r.external_id));
    } else {
      const p: JobPosting = { id: crypto.randomUUID(), business_id: businessId, ...r, first_seen_at: nowIso, last_seen_at: nowIso, closed_at: null, baseline };
      added.push(p);
      stmts.push(db.prepare(
        `INSERT INTO job_postings (id, business_id, external_id, title, url, location, department, role_kind, posted_at, first_seen_at, last_seen_at, closed_at, baseline)
         VALUES (?,?,?,?,?,?,?,?,?,?,?,NULL,?)`,
      ).bind(p.id, businessId, r.external_id, r.title, r.url, r.location, r.department, r.role_kind, r.posted_at, nowIso, nowIso, baseline ? 1 : 0));
    }
  }
  for (const part of chunks(stmts, 50)) await db.batch(part);
  // Everything seen above now has last_seen_at = nowIso, so anything open with a different value was missing from this sync.
  const closed = (await db.prepare(`UPDATE job_postings SET closed_at = ? WHERE business_id = ? AND closed_at IS NULL AND last_seen_at <> ?`)
    .bind(nowIso, businessId, nowIso).run()).meta.changes ?? 0;
  return { added, closed };
}
```

```ts
import type { RoleKind } from "../types";

// Order is priority: the first rule that matches names the role, so "SEO Content Writer" is seo and "Marketing Web Developer" is web_dev.
// Anchored on word boundaries so "cro" does not match "crop" and "ux" does not match "luxury".
const RULES: [RoleKind, RegExp][] = [
  ["cro", /\bcro\b|conversion( rate)? optimi[sz]ation|\bexperimentation\b|\ba\/b test/i],
  ["seo", /\bseo\b|search engine optimi[sz]ation|organic (growth|search)/i],
  ["web_dev", /\b(web|front[\s-]?end|full[\s-]?stack|wordpress|webflow|shopify|website)\b.*\b(developer|engineer|dev)\b|\b(developer|engineer)\b.*\b(web|front[\s-]?end|wordpress|webflow|shopify)\b|\bfront[\s-]?end\b|\bwordpress\b|\bwebflow\b/i],
  ["design", /\b(web|ui|ux|product|visual|digital|graphic)\s+designer\b|\bux\b|\bui\/ux\b/i],
  ["marketing", /\bmarketing\b|\bgrowth\b|\bppc\b|paid (media|search|social)|\bdemand gen/i],
];

/** Which part of the user's field a job title belongs to, or null when it is outside it. */
export function classifyRole(title: string): RoleKind | null {
  for (const [kind, re] of RULES) if (re.test(title)) return kind;
  return null;
}
```

```ts
import type { Fetcher } from "../crawler/crawl";
import type { Ats, RawPosting } from "../types";

export class AtsError extends Error {
  constructor(public kind: "not_found" | "http" | "bad_json", message: string) { super(message); }
}

/** A board token is put into a URL path, so it is limited to what real boards use: no slash, dot-dot, query, space or leading dash. */
export const TOKEN_RE = /^[A-Za-z0-9][A-Za-z0-9._-]{0,79}$/;
const MAX_POSTINGS = 500, MAX_TITLE = 120;

const rec = (v: unknown): Record<string, unknown> | null => (v && typeof v === "object" && !Array.isArray(v) ? (v as Record<string, unknown>) : null);
const str = (v: unknown): string | null => (typeof v === "string" && v.trim() ? v.trim() : null);
// Role links are rendered as <a href>; anything but https (javascript:, data:, plain http) is dropped.
const link = (v: unknown): string | null => { const s = str(v); return s && /^https:\/\//i.test(s) ? s : null; };
// Titles are third-party text that ends up in an AI prompt: one line, bounded.
const title = (v: unknown): string | null => { const s = str(v)?.replace(/\s+/g, " ").trim().slice(0, MAX_TITLE).trim(); return s || null; };
const iso = (v: unknown): string | null => {
  const t = typeof v === "number" ? v : typeof v === "string" ? Date.parse(v) : NaN;
  return Number.isFinite(t) && t > 0 ? new Date(t).toISOString() : null;
};
const need = (v: unknown, what: string): unknown[] => { if (!Array.isArray(v)) throw new AtsError("bad_json", `${what}: unexpected response shape`); return v; };

function greenhouse(json: unknown): RawPosting[] {
  return need(rec(json)?.jobs, "greenhouse").flatMap((j) => {
    const o = rec(j), id = o?.id, t = title(o?.title), url = link(o?.absolute_url);
    if (!o || (typeof id !== "number" && typeof id !== "string") || !t || !url) return [];
    return [{ externalId: String(id), title: t, url, location: str(rec(o.location)?.name), department: null, postedAt: iso(o.first_published) }];
  });
}
function lever(json: unknown): RawPosting[] {
  return need(json, "lever").flatMap((j) => {
    const o = rec(j), id = str(o?.id), t = title(o?.text), url = link(o?.hostedUrl);
    if (!o || !id || !t || !url) return [];
    const c = rec(o.categories);
    return [{ externalId: id, title: t, url, location: str(c?.location), department: str(c?.department) ?? str(c?.team), postedAt: iso(o.createdAt) }];
  });
}
function ashby(json: unknown): RawPosting[] {
  return need(rec(json)?.jobs, "ashby").flatMap((j) => {
    const o = rec(j), id = str(o?.id), t = title(o?.title), url = link(o?.jobUrl);
    if (!o || !id || !t || !url || o.isListed === false) return [];
    return [{ externalId: id, title: t, url, location: str(o.location), department: str(o.department) ?? str(o.team), postedAt: iso(o.publishedAt) }];
  });
}

const ENDPOINT: Record<Ats, (token: string) => string> = {
  greenhouse: (t) => `https://boards-api.greenhouse.io/v1/boards/${t}/jobs`,
  lever: (t) => `https://api.lever.co/v0/postings/${t}?mode=json`,
  ashby: (t) => `https://api.ashbyhq.com/posting-api/job-board/${t}`,
};
const PARSE: Record<Ats, (json: unknown) => RawPosting[]> = { greenhouse, lever, ashby };

/** Every public role on a board. Throws AtsError: not_found (no such board), http (any other failure), bad_json (not the shape we expect). */
export async function fetchPostings(ats: Ats, token: string, f: Fetcher, userAgent: string): Promise<RawPosting[]> {
  if (!TOKEN_RE.test(token)) throw new AtsError("not_found", "not a valid board name");
  const res = await f(ENDPOINT[ats](token), { headers: { "user-agent": userAgent, accept: "application/json" }, signal: AbortSignal.timeout(10_000) });
  if (res.status === 404) { await res.body?.cancel().catch(() => {}); throw new AtsError("not_found", `${ats} board "${token}" not found`); }
  if (!res.ok) { await res.body?.cancel().catch(() => {}); throw new AtsError("http", `${ats} answered ${res.status}`); }
  let json: unknown;
  try { json = await res.json(); } catch { throw new AtsError("bad_json", `${ats} did not return JSON`); }
  return PARSE[ats](json).slice(0, MAX_POSTINGS);
}
```

```ts
import type { Ats } from "../types";
import { TOKEN_RE } from "./ats";

export interface BoardRef { ats: Ats; token: string }

const T = "([A-Za-z0-9][A-Za-z0-9._-]*)";
// Most specific first. The host is anchored at a dot or a scheme/quote so "notjobs.lever.co.evil.example" is not a Lever board.
const PATTERNS: [Ats, RegExp][] = [
  ["greenhouse", new RegExp(`(?:^|[/."'(\\s])boards-api\\.greenhouse\\.io/v1/boards/${T}`, "i")],
  ["greenhouse", new RegExp(`(?:^|[/."'(\\s])boards\\.greenhouse\\.io/embed/job_board(?:/js)?\\?[^"'\\s<>]*?\\bfor=${T}`, "i")],
  ["greenhouse", new RegExp(`(?:^|[/"'(\\s])(?:job-)?boards\\.greenhouse\\.io/(?!embed\\b)${T}`, "i")],
  ["lever", new RegExp(`(?:^|[/"'(\\s])jobs\\.lever\\.co/${T}`, "i")],
  ["ashby", new RegExp(`(?:^|[/"'(\\s])jobs\\.ashbyhq\\.com/${T}`, "i")],
];

/** The first supported job board named in a URL or a page of HTML, or null. Tokens are checked, so a hostile page cannot name a path. */
export function detectBoard(text: string): BoardRef | null {
  for (const [ats, re] of PATTERNS) {
    const m = re.exec(text);
    if (!m) continue;
    // A sentence-ending dot or dash is not part of the name. Greenhouse and Lever names are lowercase; Ashby's are case-sensitive.
    const raw = m[1].replace(/[._-]+$/, "");
    const token = ats === "ashby" ? raw : raw.toLowerCase();
    if (TOKEN_RE.test(token)) return { ats, token };
  }
  return null;
}
```

```ts
import { readText, type Fetcher } from "../crawler/crawl";
import { latestAudit } from "../db/audits";
import { logActivity } from "../db/activity";
import { getBusiness } from "../db/businesses";
import { applySync, closeAll, getCareerSource, saveCareerSource, type SourceWrite } from "../db/jobs";
import { importUrl } from "../import/url";
import type { CareerSource } from "../types";
import { AtsError, fetchPostings } from "./ats";
import { detectBoard } from "./detect";
import { classifyRole } from "./roles";

export interface JobDeps { db: D1Database; fetch: Fetcher; now: () => Date; userAgent: string }
export interface SyncResult { added: number; relevantAdded: number; closed: number; error: string | null }

export const CHECK_EVERY_HOURS = 12, NONE_RECHECK_DAYS = 30, RETRY_HOURS = 24, EMPTY_STREAK_TO_CLOSE = 2;
const MAX_PAGE_BYTES = 400_000;

const later = (now: Date, hours: number) => new Date(now.getTime() + hours * 3_600_000).toISOString();
const errText = (e: unknown) => String((e as Error)?.message ?? e).slice(0, 300);
const noResult = (error: string | null = null): SyncResult => ({ added: 0, relevantAdded: 0, closed: 0, error });

/** Reads a lead's board once and records what is on it. Never throws for a board problem: those are recorded on the source. */
export async function syncSource(deps: JobDeps, source: CareerSource): Promise<SyncResult> {
  const now = deps.now(), nowIso = now.toISOString();
  const keep: SourceWrite = { business_id: source.business_id, status: "active", ats: source.ats, token: source.token, careers_url: source.careers_url,
    checked_at: nowIso, last_ok_at: source.last_ok_at, next_check_at: later(now, CHECK_EVERY_HOURS), empty_streak: source.empty_streak, last_error: null };
  if (!source.ats || !source.token) {
    await saveCareerSource(deps.db, { ...keep, status: "none", next_check_at: later(now, NONE_RECHECK_DAYS * 24) });
    return noResult();
  }
  let raws;
  try {
    raws = await fetchPostings(source.ats, source.token, deps.fetch, deps.userAgent);
  } catch (e) {
    // A missing board is parked for a month (the careers page may have moved); anything else may be a hiccup, so retry soon and close nothing.
    const gone = e instanceof AtsError && e.kind === "not_found";
    await saveCareerSource(deps.db, { ...keep, status: gone ? "none" : "active", next_check_at: later(now, gone ? NONE_RECHECK_DAYS * 24 : RETRY_HOURS), last_error: errText(e) });
    return noResult(errText(e));
  }
  const baseline = source.last_ok_at === null; // the first successful look says nothing about how old the roles are
  if (raws.length === 0) {
    // One empty answer is as likely a board outage as a real "no openings", so closing needs a streak.
    const streak = source.empty_streak + 1;
    const closed = streak >= EMPTY_STREAK_TO_CLOSE ? await closeAll(deps.db, source.business_id, nowIso) : 0;
    await saveCareerSource(deps.db, { ...keep, last_ok_at: nowIso, empty_streak: streak });
    return { ...noResult(), closed };
  }
  const { added, closed } = await applySync(deps.db, source.business_id, raws.map((r) => ({
    external_id: r.externalId, title: r.title, url: r.url, location: r.location, department: r.department, role_kind: classifyRole(r.title), posted_at: r.postedAt,
  })), nowIso, baseline);
  await saveCareerSource(deps.db, { ...keep, last_ok_at: nowIso, empty_streak: 0 });
  const relevant = added.filter((p) => p.role_kind);
  if (!baseline && relevant.length) await logActivity(deps.db, source.business_id, "job_found", relevant.map((p) => p.title).join("; ").slice(0, 300));
  return { added: added.length, relevantAdded: relevant.length, closed, error: null };
}

/**
 * Finds the lead's board from the careers link the crawler stored on its latest audit, then does the first sync.
 * Returns null (and records nothing) for a lead that does not exist or has not been scanned, so a later tick tries again.
 */
export async function discoverSource(deps: JobDeps, businessId: string): Promise<CareerSource | null> {
  const [business, audit] = await Promise.all([getBusiness(deps.db, businessId), latestAudit(deps.db, businessId)]);
  if (!business || !audit) return null;
  const now = deps.now(), nowIso = now.toISOString();
  const careers = audit.site_links.careers ?? null;
  const park = async (status: "none" | "error", error: string | null, hours: number) => {
    await saveCareerSource(deps.db, { business_id: businessId, status, careers_url: careers, checked_at: nowIso, next_check_at: later(now, hours), last_error: error });
    return getCareerSource(deps.db, businessId);
  };
  if (!careers) return park("none", null, NONE_RECHECK_DAYS * 24);
  // The link comes from the prospect's own website, so it is held to the same public-https rule as imported addresses.
  const safe = importUrl(careers);
  if (!safe.ok || !safe.url.startsWith("https://")) return park("none", null, NONE_RECHECK_DAYS * 24);
  let ref = detectBoard(safe.url);
  if (!ref) {
    try {
      const res = await deps.fetch(safe.url, { headers: { "user-agent": deps.userAgent, accept: "text/html" }, signal: AbortSignal.timeout(10_000) });
      if (res.ok) ref = detectBoard(await readText(res, MAX_PAGE_BYTES));
      else await res.body?.cancel().catch(() => {});
    } catch (e) {
      return park("error", errText(e), RETRY_HOURS);
    }
  }
  if (!ref) return park("none", null, NONE_RECHECK_DAYS * 24);
  await saveCareerSource(deps.db, { business_id: businessId, status: "active", ats: ref.ats, token: ref.token, careers_url: careers, checked_at: nowIso, next_check_at: nowIso });
  await syncSource(deps, (await getCareerSource(deps.db, businessId))!);
  return getCareerSource(deps.db, businessId);
}

/** The "Check now" action: re-read an active board, otherwise look for one. */
export async function checkLead(deps: JobDeps, businessId: string): Promise<CareerSource | null> {
  const existing = await getCareerSource(deps.db, businessId);
  if (existing?.status === "active") { await syncSource(deps, existing); return getCareerSource(deps.db, businessId); }
  return discoverSource(deps, businessId);
}
```

```ts
import { listDueSources, listUndiscovered } from "../db/jobs";
import { discoverSource, syncSource, type JobDeps } from "./sync";

// One tick is one batch of outbound fetches. 40 keeps it far under the Worker's subrequest limit even when discovery reads a careers page too.
export const JOB_WATCH_MAX_PER_TICK = 40, DISCOVER_PER_TICK = 15;

/** Polls the boards that are due, then spends what is left of the budget finding boards for scanned leads. */
export async function runJobWatch(deps: JobDeps, opts: { max?: number } = {}) {
  const max = opts.max ?? JOB_WATCH_MAX_PER_TICK;
  const summary = { synced: 0, discovered: 0, failed: 0 };
  const nowIso = deps.now().toISOString();
  const due = await listDueSources(deps.db, nowIso, max);
  for (const s of due) {
    try { (await syncSource(deps, s)).error ? summary.failed++ : summary.synced++; }
    catch (e) { summary.failed++; console.error("job sync failed", s.business_id, e); }
  }
  const room = max - due.length;
  if (room > 0) {
    for (const { id } of await listUndiscovered(deps.db, nowIso, Math.min(room, DISCOVER_PER_TICK))) {
      try { await discoverSource(deps, id); summary.discovered++; }
      catch (e) { summary.failed++; console.error("job discovery failed", id, e); }
    }
  }
  return summary;
}
```

```ts
  const iso = p.posted_at ?? (p.baseline ? null : p.first_seen_at);
```

```ts
import type { Ats, CareerSource, JobPosting } from "./types";

const DAY = 86_400_000;
const plural = (n: number, w: string) => `${n} ${w}${n === 1 ? "" : "s"}`;
const ATS_LABEL: Record<Ats, string> = { greenhouse: "Greenhouse", lever: "Lever", ashby: "Ashby" };
export const atsLabel = (a: Ats | null) => (a ? ATS_LABEL[a] : "");

/** How old a role is, in words. A role found on the first look at a board has no known age unless the board dated it (same rule as the Today queue). */
export function ageLabel(p: Pick<JobPosting, "posted_at" | "first_seen_at" | "baseline">, now: Date): string {
  const days = (iso: string) => Math.max(0, Math.floor((now.getTime() - Date.parse(iso)) / DAY));
  if (p.posted_at) { const d = days(p.posted_at); return d === 0 ? "Posted today" : `Posted ${plural(d, "day")} ago`; }
  if (p.baseline) return `Age unknown (on their board since at least ${new Date(p.first_seen_at).toLocaleDateString("en-US", { month: "short", day: "numeric", timeZone: "UTC" })})`;
  const d = days(p.first_seen_at);
  return d === 0 ? "First seen today" : `First seen ${plural(d, "day")} ago`;
}

export function sourceLine(s: CareerSource | null): string {
  if (!s) return "Not checked yet";
  if (s.status === "none") return "No supported job board found on their site";
  if (s.status === "error") return `Couldn't read their careers page${s.last_error ? `: ${s.last_error}` : ""}`;
  return `Watching their ${atsLabel(s.ats)} board${s.last_error ? `. Last check failed: ${s.last_error}` : ""}`;
}
```

```tsx
    api.get<{ jobs: OpenRole[] }>("/jobs")
      .then((r) => { if (alive.current) setJobs(r.jobs); })
      .catch((e) => { if (alive.current) setErr(e instanceof ApiError ? e.message : "Couldn't load open roles."); });
  }, []);
  async function runNow() {
    setMsg(""); setErr("");
    try { await api.post("/jobs/run"); setMsg("Checking boards in the background. Reload in a minute."); }
    catch (e) { setErr(e instanceof ApiError ? e.message : "Couldn't start the check."); }
  }
  const now = new Date();
  return (
    <div>
      <div className="row between page-head"><h2>Jobs</h2><button onClick={runNow}>Check boards now</button></div>
      <p className="muted">Open roles in web, design, SEO, CRO and marketing at your leads, read from their own job boards (Greenhouse, Lever, Ashby). Boards are checked every six hours.</p>
      {err && <p className="error" role="alert">{err}</p>}
      {msg && <p role="status">{msg}</p>}
      {!jobs ? (err ? null : <p role="status">Loading…</p>) : jobs.length === 0 ? (
        <div className="card"><p>No open roles yet. Boards are found for leads that have been scanned and have a careers page on a supported job board. Import a list of agencies or software companies to widen the net.</p></div>
      ) : (
        <div className="table-wrap"><table>
          <thead><tr><th>Role</th><th>Company</th><th>Age</th><th>Where</th></tr></thead>
          <tbody>
            {jobs.map((j) => (
              <tr key={j.id}>
                <td><a href={j.url} target="_blank" rel="noreferrer">{j.title} ↗</a></td>
                <td><Link to={`/leads/${j.business_id}`}>{j.business_name}</Link></td>
                <td className="muted">{ageLabel(j, now)}</td>
                <td className="muted">{j.location ?? ""}</td>
              </tr>
            ))}
          </tbody>
        </table></div>
      )}
    </div>
  );
}
```

`docs/job-watch.md`:

```markdown
# Job watch

Job watch reads the public job board of every lead that has a careers page on **Greenhouse, Lever or Ashby**, and tells you when a role in web, design, SEO, CRO or marketing appears or stays open. It runs every six hours (cron `37 */6 * * *`) and never contacts anyone: it only fills the **Jobs** page, each lead's **Open roles** card, and the **Hiring** items on **Today**.

## What it needs

A lead only gets a board if (1) it has been scanned (quick or full) and (2) its site links to a careers page that either is, or embeds, a Greenhouse, Lever or Ashby board. Most plumbers and dentists have neither, so the watcher is only as good as the companies you give it.

## Feeding it companies that hire for your field

- **Import** (the Import page): paste a CSV or a list of domains of marketing agencies, software and SaaS companies, ecommerce brands and web studios. A quick scan starts for each; boards are found on the next six-hour tick.
- **Radar / New search**: search for "marketing agency", "web design agency" or "software company" in a city you would work in.
- A lead's **Open roles → Check now** finds its board immediately instead of waiting for the tick.
- **Jobs → Check boards now** runs a full tick in the background.

## How to read it

- *Posted N days ago* comes from the board. *First seen N days ago* means the board gave no date and we noticed it after our first look. *Age unknown* means it was already there when we first looked, so we say nothing about how old it is.
- *Hiring* on Today appears for leads you have not contacted yet, when a role is 3 days old or less (reach out now) or has been open 30 days or more (they have a problem you can pitch against).
- A drafted email may mention a role only if the board showed it within the last 48 hours; the model is told to use the exact title and nothing else about the role. To write a draft without the role, send `{"usePosting": false}` to `POST /api/leads/:id/regenerate`.

## Limits

- Only three boards are read. Workable, Recruitee, BambooHR, Breezy and others are not yet.
- One empty answer from a board does not close its roles; two in a row do.
- We do not know how much earlier this is than LinkedIn. `first_seen_at` is stored so you can compare it with a role's posting time on LinkedIn for a few weeks and find out.
```
